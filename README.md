# AutoIQ 🚗
### Intelligent Used Car Valuation System

AutoIQ is a machine learning-powered used car valuation application built with Python and Streamlit.

## Features
- AI-powered used car price prediction
- Compare valuations of two cars
- Interactive market insights
- Dataset exploration and filtering
- Prediction history with CSV export

## Tech Stack
- Python
- Pandas and NumPy
- Scikit-learn
- Random Forest Regression
- Streamlit
- Plotly

## Run Locally

Install dependencies:

pip install -r requirements.txt

Start the application:

streamlit run app.py
